Embedded SQL (Oracle Pro*C) Code & Architecture

Inspect how SQL statements are embedded in host C code using Oracle's Pro*C precompiler.

1. Host Variables

Declared between EXEC SQL BEGIN/END DECLARE SECTION. Passed to SQL using a colon (e.g. :patient_id).

2. SQLCA (Communications Area)

Monitors execution status. sqlca.sqlcode == 0 (Success), 1403 (NO DATA FOUND), < 0 (Oracle Error).

3. Cursors

Handles multi-row result sets with DECLARE, OPEN, FETCH INTO, and CLOSE.

4. Indicator Variables

Handles NULL values. Indicator -1 signifies the database column contained a NULL value.
